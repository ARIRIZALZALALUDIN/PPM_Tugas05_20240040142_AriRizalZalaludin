# tugas_sesi_5 - NusaEvent Hub

Cara menjalankan:
1. `flutter create tugas_sesi_5` lalu ganti folder `lib/`, `test/`, `pubspec.yaml`, `analysis_options.yaml` dengan isi ZIP ini.
2. `flutter pub get`
3. `flutter run`

## Poster acara (gambar)
Poster ada di `assets/images/posters/` dan sudah didaftarkan di `pubspec.yaml`.
Setiap `EventItem` punya field `posterAsset`. Setelah mengganti/menambah gambar,
jalankan `flutter pub get` lalu **restart penuh** (bukan hot reload).
